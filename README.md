# 4GeeksAcademy-Guillex1180-ReactyNext

## Design References

Para el diseño del explorador de experiencias de Wanderlust Labs, nos inspiramos en las siguientes plataformas:

### 1. Airbnb Experiences
![Airbnb Experiences](https://images.unsplash.com/photo-1556911220-bff31c812dba?w=600&h=300&fit=crop)

Sistema de tarjetas visuales con imágenes de alta calidad, distribución limpia del grid responsivo y filtros persistentes en la parte superior. Referencia directa para el diseño de `ExperienceCard` y `ExperienceGrid`.

🔗 [airbnb.com/experiences](https://www.airbnb.com/experiences)

### 2. GetYourGuide
![GetYourGuide](https://images.unsplash.com/photo-1506377247377-2a5b3b417ebb?w=600&h=300&fit=crop)

Diseño enfocado en la exploración rápida con barra de búsqueda prominente, chips de categoría coloridos y precios claros por persona. Inspiración para `SearchBar` y `CategoryFilters`.

🔗 [getyourguide.com](https://www.getyourguide.com)

### 3. Viator
![Viator](https://images.unsplash.com/photo-1488646953014-85cb44e25828?w=600&h=300&fit=crop)

Estructura eficiente de tarjetas con badges de valoración (ratings), etiquetas de ubicación y botones de llamada a la acción claros. Inspiración para la visualización de `rating` y `destination` en las tarjetas.

🔗 [viator.com](https://www.viator.com)
